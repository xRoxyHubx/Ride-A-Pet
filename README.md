# RoxyHub - Ride A Pet

An advanced, feature-rich automation script for Ride A Pet on Roblox, powered by the sleek WindUI Engine.

## Features
- Smart Auto-Farm: Collects eggs using 2-Stage Anti-Cheat Safe Tweening to bypass server speed checks.
- Full Egg ESP: 3D highlights, floating text, tracers, and rarity filters (Ethereal, Divine, Mythic, etc.).
- Plot & Pets Automation: Fully automates your base with Auto-Return, Auto-Place, Auto-Hatch, and Auto-Unlock Nests.
- Auto-Feed Pets: Select multiple pets via dropdown; the bot will automatically equip the correct food and feed them continuously.
- Auto-Upgrade Luck: Spams Hatch Luck upgrades automatically using your in-game cash.
- Profile System: Save and load your configurations instantly.
- Mobile Friendly: Includes a draggable floating toggle button for mobile execution.
- Safe & Secure: Built-in Anti-AFK and Anti-Kick protections.

## How to Use
1. Attach your preferred executor.
2. Execute the RoxyHub_RideAPet.lua script.
3. Open the UI (or use the floating RoxyHub button on mobile) and configure your settings.

*Note: All toggles are disabled by default for safe loading and showcase purposes.*
